# lzy-script-coach · 智宇师兄大号文案校正

> 本技能是 LZY 自媒体方法论工具箱（/lzy）的方法之一。纯方法论技能，零脚本、零环境依赖。
> 数据规律依据（判断的唯一依据，不要用通用短视频常识替代）全部内嵌在正文中，随实战持续回写迭代。

## help 协议

**每次运行开头，先静默执行版本检查**：`bash scripts/check_update.sh`。如果输出 `UPDATE_AVAILABLE ...`，在回复开头告诉用户「此技能有新版本，可以让 AI 同步更新」。无输出则不打扰。

如果收到的参数是 `help` / `用法` / `怎么用`，或没有给口播文案，直接输出以下用法说明后停止，不做任何评判：

```
lzy-script-coach · 智宇师兄大号文案校正 · 用法

/lzy-script-coach <口播文案>
  例：直接粘贴一段口播稿全文
  例：/lzy-script-coach ~/Desktop/脚本.md

做什么：主题闸门（否决/强制改写）→ 七项体检打分（第1项翻倍）→ 总分与预估认人效率 → 最小改动改写
适用：仅大号「智宇师兄」（服务老板/ToB，目标拿客户）
不适用：小号「智宇说商业」「智宇-健康行业IP打造」（超短句打法，规则不通用）
```

## 何时用

用户贴来一段口播文案 / 脚本，要求评判、打分、改写。

**用户说「我又写嗨了 / 又被启发到了 / 这条又写成教育口吻了 / 帮我回到框架」时，先走下面「自嗨急救」，不要直接打七项分。**

## 自嗨急救（写嗨了怎么回框）

**根因不是不会写，是触发源错了。** 判据一句话：**你的情绪是对着一个具体的人，还是对着一个道理？**
- 对着人（某个客户卡住了、我替他着急）→ 直接写，情绪是好燃料
- 对着一个道理（我刚想通一个事、我必须告诉所有人）→ **先去找那个人，找不到就别写**

**为什么改不回来**：一旦进入"我要把这个道理讲清楚"，你的表达欲会绑架判断力，写完后自读越读越顺，靠意志力拉不回来。所以唯一可靠的是**写前锚定**。

**写前锚定（唯一真正有效的一道闸）**：开写前先写下一句**真实客户最近说过的话**（微信/咨询记录/评论区里的原句），把它放在文档第一行当锚。没有原话就先去找，找不到说明这条还不到写的时候。

**写后三步转换（已经写嗨的稿子，按序机械执行）**：
1. **换人**：把第一句里的抽象概念/"你要"/"第一"，换成一个具名的人和他的处境（行业 + 卡了多久 + 他原话怎么说的）。人的名字写不出来，这条就不是内容，是讲义。
2. **砍到只剩一条**：三条特征 / 四个步骤 → 只留一条。用**盖名测试**挑留哪条：把你的名字盖住，问"同行能不能原样讲一遍？"——能讲的都是通用知识，全砍；**只有那个他讲不了的（来自你自己的案例）才留下**。
3. **换动作**：结尾不要"只要你做到这 N 点就一定……"。换成一句**诊断型动作**："你回去翻翻你的 XX，数一下有几条是 A、有几条是 B"。观众自己一数就发现问题 = 缺口还在。

**最后补一刀（郑经说善意维度）**：加一句「这套不适合谁 / 你要是 XX 就别这么做」。

## 何时不用

- 小号「智宇说商业」「智宇-健康行业IP打造」的文案 → 那是超短句打法，规则不通用
- 只写标题、不写正文 → 用数据规律给选题建议即可
- 用户要的是从零创作而不是校正 → 另走创作流程

## 执行

按下面流程做，这是完整提示词，直接使用。

### 第一步：主题闸门（两层，不是一层）

⚠️ **不要只看标题关键词**。实测 22 条里被判为「边缘」的 7 条，标题**全部**含「获客 / 客资 / 成交 / 客户」。关键词会骗人，要看内容实际在讲什么。

**闸门一（否决，不改写）**：影视读书、行业宏观观察、个人感悟、纯观点、线下活动。
→ 直接回：「这条属于 XX 方向，实测关注率 0.06–0.10%，只能带来流量幻觉，沉淀不下精准粉丝。建议换选题，别浪费发布位。」再给 2 个替代选题方向。

**闸门二（不是否掉，是必须改写）**：讲的是**模型 / 阶段 / 分类 / 认知层级 / 通用道理**，而不是用户当下卡住的**某一个具体场景**。
典型：「高客单成交的 3 个阶段」「客户的 5 层认知」「4 个步骤教你拍出获客短视频」。
→ 改写成「一个具体场景 + 你的判断 + 一个可当场做的动作」。标题里的「获客」「成交」不算数，得看正文有没有一个用户能认领的处境。

**目标单元格（四条件叠加，缺一不可）**：核心主题 + 重新定义问题 + **嘴替** + 给到一个诊断型动作。
- 核心+重构+嘴替+动作 n=5：关注率 **0.662%**、分享率 0.966%、认人 **70**、播放指数中位 1.37 —— 全样本最优
- 上一版 n=3（7/24、8/4、8/6，0.83%）回头看**三条全部有嘴替**，所以那不是缺嘴替的反例，是嘴替早隐含在里面
- ⚠️ **嘴替不接动作 = 全场第二差**：有嘴替但没给动作 n=3 关注率 **0.098%**（7/19、8/15、8/13），比"没嘴替但给了动作"（0.144%）**还低**。只安慰不指路，比只给工具更糟。

**理论校准（郑经说体系，2026-09-07 核对）**：三条与郑经说内容生意课完全同构，属「理论预言 + 数据验证」双证——
- 核心主题 ＝ **定位的本质是占领一个具体问题**（不是锁定人群），且必须是**向内求解**型（找方法）而非向外归因型（找共鸣）。
- 重新定义问题 ＝ **判断三段位的「高级/原诊断」**：在 A 背后找到 B，甚至推翻用户对问题本身的定义；配**信息缺口理论**（"原来是这样" + "但我自己怎么弄"）。
- 给动作 ＝ **「每条只给一个动作」**（三条死规矩之一）。
- ⚠️ **唯一冲突**：郑经说同时说「方向只出大方向，不讲具体步骤」「步骤讲完＝缺口填平＝用户不需要你」。解：**只给诊断型动作，不给方案型动作**（见③）。

**「重新定义问题」比「非框架非清单」更本质，两者不是一回事**（有重构且是清单体的仅 8/13 一条，不共线）：
- 核心组内：有重构 vs 无重构 → 关注率 0.57% vs 0.30%（1.9 倍）、**认人 82 vs 36（2.3 倍）**
- **但非核心组内：0.11% vs 0.12%（0.92 倍，完全无效）**。重构是核心主题上的**乘数**，不是替代品。
- 反例：**8/13 是全场最纯粹的重构**（「你这个问题就问反了」），关注率 **0.03% 全场最低** —— 因为它是非核心 + 清单体 + 没给动作。

**传授体系化知识 ≠ 展示解决问题的能力（数据确认）**：8/20 讲平台算法逻辑，播放指数 **1.80 全场最高**、分享率 1.25%，但**认人只有 49**（低于健康线 57）——被当工具收藏，没被当人跟随。对照 7/23 播放指数 1.70，**认人 108**。同样的播放量，认人差 2.2 倍。

⚠️ **非框架非清单只是「重新定义问题」的弱代理**：它只能挡住最糟的（模型/模板型），挡不住「有判断但不推翻问法」和「推翻了问法但没给动作」。所以 ⑥⑤ 保留为结构红线，但真正要盯的是 ④。

顺序不能反：**先确保是核心主题 → 再问有没有推翻观众的问法 → 最后必须给动作**。写法的优化只在核心主题上有效：核心组内改写法 0.26%→0.49%，非核心组内改写法 0.12%→0.22%（绝对值仍低于核心组下限）。

### 第二步：七项体检（每项 0/1/2 分，第 1 项翻倍）

| # | 检查项 | 2 分 | 0 分 |
|---|---|---|---|
| ① 【翻倍】 | 开场切入 | 客户具体处境或直接引用的原话开头 | 我的成果 / 我的研究 / 抽象概念开头 |
| ② | 「我」的位置 + 案例主角 | 结果一句话带过，立刻转向「你怎么用」；**案例主角是跟你一样的客户，最好是踩坑** | 通篇讲我做到了什么、我多满意；**或案例主角是我的成果／牛人／大数字** |
| ③ | 可带走的东西【只认诊断型】 | 一句原话级话术 / 一个当场能做的自检 / "你回去看看你的XX是不是这样" | 只有判断没动作；**或给的是方案型动作**（完整流程、可套模板、N 步走）——步骤讲完＝缺口填平＝用户不需要你 |
| ④ | 重新定义问题（＝原诊断） | 推翻观众原有问法／归因，让他意识到"我这个问题本身就问错了" | 只传授体系化知识、给通用模板、或只有描述 |
| ⑤ | 清单体（反向） | 无「N 个要素/步骤/层/点/条/种」 | 出现了 |
| ⑥ | 单点聚焦 | 只讲一个处境 | 塞了两个以上 |
| ⑦ | 嘴替（替客户说话） | 核心判断就是一句观众能原样转述的"免罪/许可"句：你不是不会拍、不用追粉丝、不用每天想新选题 | 通篇讲客观道理/我的方法；**或有责备口吻**（"不理解这点的老板就是在浪费钱"） |

**⑦ 的判分细则（薛辉：站在潜在客户立场，替他想做的事找借口、不想做的事找理由）**：
- **2 分**：全篇主轴就是替他说一句他自己说不出/不敢说的话，且**他能把这句原样转述给同事**
- **1 分**：局部有"不是你的问题""不是你内容不好"，但不是主轴
- **0 分**：客户只是被分析的对象；或带责备口吻
- 数据：嘴替≥1（n=12）认人中位 50.9 vs 嘴替 0（n=9）26.1，**1.95 倍**；关注率 0.383% vs 0.157%（2.4 倍）
- **与「重构」不共线**：在 rf=2 组内，嘴替 2/1/0 分认人仍为 87.5 / 53.8 / 26.1
- ⚠️ 只验证到**免罪型**（替他不想做的事找理由，n=11）；许可型（替他想做的事找借口）数据里只有 8/15 一条，无法验证

**爹味自检（2026-09-09 新增，必做）**：

> **爹味不是"话太硬"，是"你说硬话的时候，屋里没有一个人"。**

- 数据：脚本里**认领标记**的密度（"前几天/上周/昨天/有个/一个老板/他问我/他说/弹幕/评论区/后台/客户说/来找我做咨询"）与认人效率 **r = +0.553** —— 本项目 7 类文本扫描里**唯一超过 0.3 的信号**
- **说教词**密度（"一定要/必须要/你应该/别再/老板们/记住/否则/赶紧/趁早"）与认人 **r = +0.14，几乎无关** → **说硬话不扣分，没人在场才扣分**
- 对照：8/06 说教词 7 个但认领词 6 个 → 认人 **105.7**；7/29 说教词 2、认领词 **0** → 认人 20、关注率 0.029%；8/18 说教 3、认领 1 → 33.3；8/30 说教 1、认领 0 → 26.7

**判据（10 秒）**：挑出全篇最硬的那句判断句，往前看三行——**有没有一个具体的人？** 有名字/行业/原话 = 替他着急，不是爹；只有"老板们""很多人"这种泛指 = 对着虚空下指令 = 爹味。

**修法不是把话变软**（变软会丢判断密度，更糟），而是**把人放进来**：硬话前面加一句「上周有个做 XX 的老板跟我说……」就够。

**卡点具体性（同一件事的另一面，三档单调）**：具体到场景 n=3 → 认人 87.5 / 关注率 0.755%；有卡点但不具体 n=11 → 34.6 / 0.267%；抽象讲模型 n=7 → 26.7 / **0.115%**（差 6.6 倍）。⚠️ conc=2 只有 3 条且与已知最优组重合、conc=0 里 4 条是清单体，**共线，只能当方向性证据**。

**① 的判分细则（极容易误判，务必照此）**：
- **2 分**：第一句出现的是**客户**——具体的人、具体的处境，最好是他亲口说的原话
- **1 分**：第一句是我自己的经历。**即使是我踩过的坑、写得再有代入感，也只能给 1 分**——观众代入的是"这人挺真诚"，不是"这说的是我"
- **0 分**：我的成果、我的研究、抽象概念、清单体开头

**开头钩子强度检查（改写完必做）**：前 3 秒必须三选一，否则钩子不够强——
1. **反转归因**：观众本来以为是自己 XX 不行，你说不是，是 YY（例："不来客资不是内容不好，是你解决了个用户没说过的问题"）
2. **点名损失**：先把他的损失说出口（例："拍了一百条，没一条来客资"）
3. **客户原话**：直接让一个和他一样的人开口

自检：把第一句单独念出来，问"观众听完是想'然后呢'，还是想'跟我没关系'"。想"跟我没关系"就是钩子失败，必须重写。

**同轴检查（改完必做，否则观众会觉得"哪儿怪怪的"）**：把全文三个关键件抽出来——① 开头断言 ② 案例/证据 ③ 给的动作，问一句：**这三件是不是在讲同一个判断？**

常见错配（必须避免）：
- 案例讲 A 病，客户处境讲 B 病（例：案例讲"听错了用户说的"，处境讲"压根没听用户"——这是两种病）
- **案例说"用户嘴上说的不可信"，动作却让人去抄用户嘴上说的原话**（自相矛盾，最常犯）
- 结尾总结的判断，和案例真正证明的判断不是同一个

修法：先定一个判断句（如"愿望不掏钱，卡住的地方才掏钱"），拿它同时检验钩子、案例、动作、结尾。通不过就换案例或改动作，**不要靠加过渡句糊过去**。

**案例铁律（不单列计分，但改写必须满足）**：
- ✅ 案例主角是"跟你一样的客户"，**最好是踩坑**：认人中位 **70.7**（n=6），核心主题组内 **105.7**（n=3）
- ❌ 案例主角是我的成果／牛人／大数字：认人中位 **42.7**（n=7）。⚠️ 这类**分享率反而最高（0.855% vs 0.445%）**——被当成"可以转走的素材"，不是"要跟着的人"。讲我的成果 = 高分享低认人，白嫖感最强
- ❌ 没有具体案例只讲道理：认人中位 **26.5**
- 控制主题／控制动作／控制嘴替三个检验排序都不变 → 独立变量
- **必须讲我的成果时，一定带"我也可以"的低门槛信号**，否则差 5 倍：
  - 有信号（"一小时拍 4 条""每周只花 2 小时""播放量没很大"）n=3 关注率 **0.708%**
  - 纯炫耀（"第 4 天出爆款""3 个人干 3000 万""投入 2 个人 2 个月，我对结果比较满意"）n=4 关注率 **0.140%**
  - 极端对照：同为 GEO 主题，8/04（"一小时拍 4 条"）认人 81.8／关注率 1.215% vs 9/04（"2 人 2 个月"）认人 14.8／0.182%，**差 5.5 倍，只差在门槛信号**
- ⚠️ 本数据里"主角是同水平客户"与"案例是踩坑"完全重合（peer 6 条全踩坑、self 7 条全成功），无法分离，但都指向：**能认领 > 只能仰望**
- 📌 23 条里"我也可以做到"型的**正面客户成功案例 = 0 条**，从未验证过

### 第三步：总分与预估

- 13–16 分：预估认人效率 > 57，好内容
- 10–12 分：30–57，一般
- < 10 分：< 30，等于替别人做嫁衣

### 第四步：改写

**铁律**：保留用户的判断和原话不动，只调结构与开场。最小改动——能改开头就不重写全文。原文已经好就直说「不用改」，别硬改。

**结构顺序**：处境（客户原话）→ 我的判断（不是 X，是 Y）→ 机制拆解（1–2 层）→ 可带走的动作（**诊断型**，最好给原话）→ 我的结果当证据（一句话，放在判断之后，不放开头）→ **缺口感结尾**

**结尾铁律（信息缺口）**：
- ❌ 不用"所以总结一下……""你把这 N 件事做对了就……"收口 —— 讲完＝缺口填平。8/22 认人 43、8/25 认人 16 就是这么死的。
- ✅ 结尾明确留"还差的那一点"并指明在哪："第二步下条讲"／"完整判断得看你的行业"／咨询入口。8/20 用"这是第二步，下条再讲"收尾，关注率 0.61%。
- 自检：观众看完，"还差的那一点"是不是仍然只有你能补？不是，就是动作给多了。

**善意维度（信任＝能力×善意×诚信，大多数只建了能力）**：
全篇要有一句"**这套不适合谁**"或"**你要是 XX 就别这么做**"。敢说不适合的客户，是建立善意维度成本最低的方式，也是"关注→加微咨询"之间那堵墙。注意：核心主题／重构／给动作这三条**全部只建立能力维度**——这很可能是关注率上去了但加微和成交没起来的原因。
