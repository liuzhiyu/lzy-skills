# 临床用药 / 常见药品 行业词库
#
# 用法：python3 scripts/transcribe.py --input 视频 --domain drug
#       python3 scripts/polish.py --input 已有稿.txt --domain drug
#
# 与 health.txt 的区别——别混用：
#   health = 功能医学 / 营养 / 抗衰（胰岛素抵抗、辅酶Q10、线粒体…）
#   drug   = 临床用药 / 药品名 / 用法与不良反应（布洛芬、阿司匹林、胃出血…）
# 一条视频同时涉及两者时叠加使用：--domain health,drug
#
# 为什么必须分开：Whisper 的 initial_prompt 只有 40 字预算，只放得下 5-6 个词。
# 词表混在一起，本篇真正会出现的药名就挤不进提示，等于没注入。
